# 中文 Word 文档原地修订

场景：拿到一份已经写好、排好版的 .docx，要求改错字、改句子、补参考文献、删章节。交付物必须还是原来那个模样——字体、行距、标题样式、目录域、分节页码全不能动。

## 铁律：不要重新生成

不要用 md → docx 的生成器重做一份。原作者是用 Word 手工排的版，样式表里一堆继承关系，重新生成等于重排，返工量比改字大得多，还容易丢目录域和分节。**改动量再大，也走原位替换。**

## 标准流程

1. 读原文，摸清结构：段落数、样式分布、有没有自动编号、参考文献怎么排的。
2. 把要改的地方写成“旧句 → 新句”对照表。
3. 脚本跑一遍：`Document(原文件)` → 遍历 paragraphs → `p.text` 匹配 → 改 run 文本 → `save(新文件名)`。
4. 打印命中数与未命中项。**未命中说明原文跟预想不一样**，回去读原文再改，不要硬凑替换。
5. 转 PDF，逐页目检。
6. 逐个替换处回读前后两三句，查语义重复。

## 三个必查的坑

### 1. 自动编号撞字面编号

段落带 `pPr.numPr` 时，Word 会额外渲染一层编号，而字面又手打了一遍，PDF 上就成了“第一，第一，”。

**docx 文本层是干净的，只看 docx 查不出来，必须转 PDF 才看得见。**

诊断：

```bash
python scripts/inspect_numbering.py 待查.docx
```

修法：删掉该段落的 numPr 保留字面编号，或反过来删字面保留自动。**全篇必须统一**，别一半自动一半手写。

### 2. 参考文献一般是自动编号

条目本身不写 `[1]`，交给 numPr 生成，增删条目不用手动重排。原文如果是这样，你补条目时**不要手写编号**，只写正文部分，编号会自己跟上。反过来说，如果你手写了编号，PDF 就会出双份。

### 3. 替换句语义重复

改掉一句口语化表达，很容易跟前一句说同一件事（例：前文已说“迁移到表演艺术场景”，替换句又写了一遍）。这种叠床架屋比错别字难发现，也更难看。**改完把前后各两三句连起来读一遍，宁可少改一句。**

## 交付

- 另存新文件名，不覆盖原件。
- 附改动清单：哪几处、原句、新句、为什么改。
- 存疑项单独列：查不到的文献、推算的期号页码，明确写“待你核”，不要混在“已改好”里。
