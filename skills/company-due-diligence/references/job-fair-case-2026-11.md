# 实战记录：云南省 2027 届艺术类专业高校毕业生专场招聘会（2026-11-05）

## 任务形态
主人给了 4 张展位名录照片（A001–A125，每张一页，OCR 拼出全量）+ 一份简历 PDF，要求“全部公司三轮筛选：① 筛掉野鸡 ② 筛剩下的 ③ 选待遇好福利好适合的”，明确要求爬虫 + 多子 agent。

## 时间线（全程约 50 分钟）
1. OCR 四张图 → 124 个去重主体（125 展位，A123 与 A069 同一家）。
2. 抽简历（pymupdf `page.get_text()`；PDF 直接 read_file 会报 binary）。
3. 建 `companies.tsv`（id\t名称）+ 抓取脚本 + 判定用 `CRITERIA.md`（打分表 + 求职者画像）。
4. 6 个子 agent：3 波 ×2（R1 判 A047–A090 / A001–A031 / A091–A125 / A032–A046；R2 分文旅组、教育品牌组）。
5. 合并 CSV → `tiers.tsv`（人工定梯队）→ xlsx + docx。

## 引擎实况（同一 IP、同一天连续跑）
| 引擎 | 撑到第几家/多少次 | 表现 |
|:--|:--|:--|
| 360 桌面版 | 约 56 家 ×3 查询后封 | 封后只回 9.8KB 验证码页，等 30 分钟仍未解，换 iPhone UA 撑了一会儿也封 |
| 搜狗 | 约 60 次 | 403（564 字节）；解封后单线程可用，**公司名加英文引号**效果最好 |
| 神马/夸克 | 约 30–40 次 | 之后返回空正文不报错（最容易被误判成“查无此公司”） |
| 头条 | 80+ 家 3 轮未封 | 本轮主力：一家 1000–2000 字，含 BOSS 岗位薪资、中标记录、地方媒体 |
| 天眼查 | **3 次** | 极脆但最香：搜索页/详情页 `__NEXT_DATA__` 直接给注册资本、员工人数(2025 年)、自身/历史风险计数；第 4 次起只回 22KB 骨架 + 扫码登录墙 |
| Bing | — | 换 5 个 query 返回同一份缓存页，完全不可用 |

教训：**不要一家跑 3 个查询**（124×3 必封）。改成每家 1–2 个高价值查询 + 多引擎轮换，比“一个引擎跑到底”稳得多。

## 三轮结果分布（124 家）
硬淘汰 10 / 高危 20 / 待确认（异地·岗位不对口）17 / 可略过 36 / 备选 29 / 值得投 7 / 必去 5。

**A 档 5 家**（可复用的判断逻辑）：
- 新三板会展公司：8–12K·14薪 + 参保 84 人 + 省博庞贝展 → 薪资福利最实
- 新东方系：六险一金 + 双休 + 实习 100–120 元/天 → 名企福利明确
- 安踏：新零售管培（短视频）+ 品牌活动岗 → 但要防“落到门店导购”
- 本土职教：**唯一明码标价**“新媒体专员 4500–5900” → 岗位真实度最高
- 本土活动执行公司：广电 AIGC 大会执行 + 火把节晚会 → 与“泼水节总导演”经历严丝合缝

## R2 修正了 R1 的三处误判（关键价值）
- 省属演艺集团传媒：R1 排第一 → R2 发现公开岗位是“演员（需直播）”、base 南京 → 降为“待确认·异地”
- 头部 MCN：行业第一，但**当地无办公点**，专场大概率是主播招募 → 降为“岗位存疑”
- 文旅科技公司：注册资本 1000 万看着行，实际 4 个月前才成立、主体异地、零业务痕迹 → 从“观察”降到“不推荐”
