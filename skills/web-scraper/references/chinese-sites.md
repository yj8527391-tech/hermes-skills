# 中文网站爬取注意事项

## 通用策略

### 反爬应对
1. **Headers** — 必须设置真实的User-Agent，模拟浏览器
2. **Cookies** — 部分站点需要先访问首页获取cookies再请求
3. **请求频率** — 至少间隔1秒，建议2-3秒
4. **代理IP轮换** — 使用 `proxy_rotator.py` 模块

### 国内搜索引擎状态

| 搜索源 | 可爬取性 | 说明 |
|:------|:--------:|:------|
| 百度搜索 | ❌ 不可 | Python requests被重定向到验证页，需要浏览器cookies |
| 搜狗微信 | ⚠️ 部分可 | 搜索结果可提取，文章链接被反爬 |
| 必应国内版 | ✅ 可 | 国内可访问，反爬较弱 |
| 知乎 | ⚠️ 部分可 | 公开页面可访问，搜索需要登录 |

### Pre-commit Code Verification Skills

在提交代码前，对受影响的爬虫逻辑进行验证，避免反爬升级后静默失败。

## 代理IP注意事项

- 免费代理列表（geonode.com等）在境内可能无法访问
- 可以从国内代理源抓取（如快代理、芝麻代理等付费服务）
- 免费代理存活率通常低于20%，需要大量备用
- 对于需要登录的站点（小红书、知乎），代理也无用
