# 小六壬占卜（诸葛马前课）

## 小六壬是什么

小六壬，又称**诸葛马前课**，是中国传统占卜术数之一，相传出自诸葛亮行军途中"袖占一课"。
它属于简易占卜法：不需要复杂排盘，仅凭**农历月、日、时**三个数字，在六个掌诀间推算，
就能得到吉凶断语。因其简单快捷、随时随地可用，在民间流传极广。

**六宫掌诀**（固定顺序）：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡

## 排盘规则（必须按此推算）

### 掌诀顺序与位置
六个掌诀按固定顺序循环：`大安(1) → 留连(2) → 速喜(3) → 赤口(4) → 小吉(5) → 空亡(6)`

### 起课三步（从大安起，顺数）
1. **月**：正月从大安起，顺数到所求农历月
2. **日**：从月落宫起初一，顺数到所求农历日
3. **时**：从日落宫起子时，顺数到所求时辰（子=1，丑=2 … 亥=12）

**最终落宫 = 末传（时上落宫）**，即断卦结果。三传（月/日/时）可辅助参考。

### 数学模型（脚本已实现，勿手算）
```
chu  = (month_no - 1) % 6 + 1          # 月落宫
zhong = (chu - 1 + day - 1) % 6 + 1    # 日落宫
mo    = (zhong - 1 + shichen - 1) % 6 + 1  # 时落宫（shichen: 子=1…亥=12）
```

### 时间要求
- 必须用**准确的年月日 + 具体时间**（精确到小时即可，分钟可选）
- 脚本自动转换为农历月日 + 时辰（内置 bazi_core.py，真太阳时校正）
- 23:00-23:59 属次日子时，脚本已处理并验证（见下方测试用例）

### 对话式解读模板（用户问什么就重点讲什么）
1. 先报结果：今日/此刻起课，落宫【X】（吉/凶）
2. 按用户所问展开：
   - 问事业 → 讲工作/进展/小人
   - 问财运 → 讲正财/偏财/破财
   - 问感情 → 讲关系/桃花/争吵
   - 问健康 → 讲对应脏腑/注意事项
   - 问失物 → 按断语方位提示
   - 问出行 → 按吉凶给建议
3. **断语个性化**：脚本输出的 `quick`/`detail` 是**基础断语**，不要照念——必须结合用户的具体情境改写：
   - 带入用户描述的事件细节（如"你说的那个项目推进慢，正应留连的'事难成、宜缓'，但'急讨方称心'提示催一催反而有结果"）
   - 用当代生活语言翻译（"官非"→"纠纷/背锅"、"行人"→"没回消息的人"）
   - 同一落宫问不同事，解读侧重不同（大安问考学=稳扎稳打能上岸，问投资=别冒进）
4. 必附免责声明（见下）

## 使用流程（对话）

1. **默认可不报时间**：用户来问就直接用**询问时的准确时刻**起课（脚本自动取当前时间），无需用户报时间——小六壬本就讲究"随口问、当下起"，当下时刻即天机
2. **特殊情况才问时间**：仅当用户**明确指定**测某时（如"帮我看看明天下午3点适不适合签约"、测某个特定事件发生时间）时，才用用户给的时间，否则一律用当下时刻
3. **问所求**：询问用户想求什么（事业/财运/感情/健康/失物/出行/其他）
4. **起课**：调用脚本算出落宫（默认不传 date/hour，即取当下；特殊时间才传）
5. **解读**：用大白话 + 结合所问事项解读，避免术语堆砌
6. **锐评**：末尾俏皮一句
7. **免责**：必附"传统文化推演，仅供娱乐参考"
