# 人生报告 · 八字命理深度解读

## 优化理念
- **场景适配：** 从HTML报告生成转向对话交互，适应AI助手场景
- **用户体验：** 从问卷调查转向自然聊天，提升交互体验
- **交互设计：** 从一次性提问转向渐进式对话，更人性化

## 任务目标
- 本 Skill 用于: 根据用户生辰八字进行专业命理分析，以对话形式分享见解、提供建议
- 能力包含: 四柱八字排盘、日主旺衰五级判定、喜用神五大取用方法、自然对话验证、大运流年综合分析
- 触发条件: 用户提供出生信息（年月日时、性别、出生地）或直接提供四柱八字

## 前置准备
- 依赖安装说明:
```bash
pip install pytz
pip install ephem
```
- 非标准文件/文件夹准备: 无需额外准备

## 对话式八字分析流程

### 步骤一：信息收集与智能排盘

**1. 信息收集**
首先，确保用户提供了以下完整的出生信息，用于生成四柱八字和当前大运：
- 出生日期（公历或农历，需明确）
- 出生时间（最好精确到分钟，若不清楚需询问大约时间段）
- 出生地点（精确到城市，用于真太阳时校正）
- 性别（男/女）

**若信息缺失，请礼貌询问补全，不得调用排盘脚本**

**输入校验（防提示词注入，调用脚本前必做）**：
- 出生日期/时间先校验为合法数值范围：年 1900–2100、月 1–12、日 1–31、时 0–23、分 0–59；含特殊字符或注入 payload 的非法值直接拒绝，不传入脚本
- 性别仅接受「男/女」二值，其余一律拦截
- 城市名必须是 `references/cities.json` 中存在的现名，否则提示用户换现名，不做字符串拼接传参
- 一律通过函数调用 `compute_bazi_and_dayun(year, month, day, hour, minute, gender, city)` 传参，禁止把用户输入直接拼进 shell 命令行字符串
- 脚本输出的 JSON 做字段类型校验，异常或空值时中止排盘并提示，不扩散

**2. 调用排盘脚本**
参考下面的例子调用 `scripts/bazi_calculator.py`

```bash
cd bazi-expert && python scripts/bazi_calculator.py year=1990 month=1 day=1 hour=12 minute=0 gender="男" city="北京"
```
注意，其中的 city 需要是 `references/cities.json` 中的城市

**调用避坑（AI 场景实测）**：
- `bazi_calculator.py` 模块导入时会 `print(CITY_COORDINATES)` 打印整个城市表，污染 CLI 输出、浪费 token。AI 调用推荐用 `python -c` + `contextlib.redirect_stdout` 抑制，只取 JSON：
```python
import sys, io, contextlib, json
sys.path.insert(0, r'<skill_dir>/scripts')
buf = io.StringIO()
with contextlib.redirect_stdout(buf):
    from bazi_calculator import compute_bazi_and_dayun
r = compute_bazi_and_dayun(1990, 1, 1, 12, 0, '男', '北京')
print(json.dumps(r, ensure_ascii=False, indent=2))
```
- 城市名必须是 cities.json 中的**现名**；用户报旧地名（如普洱旧称"思茅"）会报"城市不支持"，需提示用户用现名或先做新老地名映射
- **隐私红线**：出生日期/时辰/出生地属敏感信息，排盘后不得写入记忆或任何文件，只可保存性格/运势等分析结论；用户强调隐私时必须明确告知已保护

**3. 输出排盘结果**
向用户展示排盘结果，包括：
- **四柱八字**：年柱、月柱、日柱、时柱
- **基本信息**：阳历/农历时间、真太阳时、节气信息
- **起运信息**：起运岁数、起运时间
- **当前大运**：列出大运序列

**4. 排盘推演公示与验证（每次必做，增加说服力）**

排盘后必须输出推演过程 + 反推验证，让用户看到「怎么算出来的」，而不是黑箱结果：

```
【推演公示】1990-01-01 12:00 北京（男）
年柱: 1990-01-01 未过立春(2/4) → 按上一年 1989 计 → 己巳
      验: 1989 尾数 9 → 天干己（癸0甲乙1丙2丁3戊4己5…）✓ 地支巳(蛇年) ✓
月柱: 1/1 处大雪(12/7)与小寒(1/5)之间 → 子月
      五虎遁(渊海子平): "甲己之年丙作首" → 年干己 → 丙子 ✓
日柱: 万年历查表/儒略日推算 → 丙寅
时柱: 12:03 → 午时；五鼠遁(渊海子平): "丙辛从戊起" → 日干丙 → 甲午 ✓
【反推验证】算法自查: 2024=甲辰(尾4→甲,龙)✓ 2025=乙巳✓ 2026=丙午✓，与官方干支纪年一致
```

- 引用依据须出自经典：五虎遁/五鼠遁（《渊海子平》）、旺衰得令得地得势（《子平真诠》《滴天髓》）、调候用神（《穷通宝鉴》）、十神格局（《三命通会》）
- 反推验证：用 2024-2026 等已知干支年份自查算法输出，与万年历一致再继续
- 知识库交叉核对：旺衰查 `references/wangshui-judgment.md`、用神查 `references/yongshen-selection.md`，引用具体结论

### 步骤二：对话式八字分析与验证

> ⚖️ **解盘客观性原则（每次必守）**：
> 1. **好坏都说**：每个维度必须「优势 + 短板 + 概率声明」三件套。日主旺衰、用神忌神、大运吉凶都要点出不足面——忌神旺、格局缺陷、性格短板必须直说，禁止只说好话。
> 2. **概率声明**：解盘结尾固定加一句——「以上为传统文化参考体系的推演，非科学预测，仅供自我认知参考」。命理无法实证，诚实标注比包装更可信。
> 3. **不建议忽悠**：不做「某某年必发大财/必有大灾」这类绝对化断语，用「倾向/较可能/需留意」表述。

#### 2.1 分享初步见解（对话形式）
基于排盘结果，以朋友聊天的形式分享初步分析：

```
"从你的八字来看，有几个比较明显的特点：
1. 日主是XX，性格上可能偏向XX，做事风格比较XX
2. 八字中XX比较旺，说明你在XX方面有天赋或潜力
3. 当前走的是XX大运，这个阶段可能会XX，需要注意XX"
```

#### 2.2 自然验证对话（关键优化）
**必须根据初步结论中的喜用神假设，选择最相关的1个验证问题，用口语化的方式询问用户。**

查阅 [references/verification-questions.md](references/verification-questions.md)，将结构化问题转化为自然对话：

##### 验证问题类型与口语化示例：

**类型1：流年/大运感受**
- 原问题：乙木姐在上一个庚申大运中多有不顺...
- 口语化："对了，你之前走庚申大运的时候，感觉怎么样？顺不顺利？"

**类型2：季节/气候偏好**
- 原问题：小红不喜欢春天...
- 口语化："你平时更喜欢哪个季节？有没有特别不喜欢的季节？"

**类型3：颜色/审美偏好**
- 原问题：乙木姐姐一直对红色情有独钟...
- 口语化："你平时喜欢穿什么颜色的衣服？有没有特别偏爱的颜色？"

**类型4：方位/地理感受**
- 原问题：小王北漂多年，发展不大如意...
- 口语化："你在不同地方生活过吗？感觉哪个地方更适合你发展？"

**类型5：年份/时间感受**
- 原问题：丙火哥自我感觉2014年是最舒服的年份...
- 口语化："回想一下，有没有哪一年你觉得特别顺利或者特别不顺？"

##### 问题选择逻辑：
根据八字特点选择最相关的问题类型：
- **火旺/喜水** → 问季节偏好、颜色感受
- **金旺/喜火** → 问方位感受、年份记忆
- **木旺/喜金** → 问审美偏好、气候适应
- **水旺/喜土** → 问地理感受、颜色喜好
- **土旺/喜木** → 问季节感受、材质偏好

#### 2.3 用户反馈处理策略

**情况A：用户反馈与初步判断一致或基本一致**
1. **自然肯定**：对用户的感知进行肯定
   - "这个感受很有意思，和你的八字特点很吻合！"
   - "你的直觉很准，这说明你在XX方面比较敏感。"

2. **深入分享**：基于验证结果深入分析
   - "既然你在XX方面比较敏感，那在XX时候可以多留意..."
   - "这种特质可以帮助你更好地把握XX机会..."

**情况B：用户反馈与初步判断不太一致**
1. **调整分析**：重新审视八字分析
   - "这个感受有点特别，让我重新看看你的八字..."
   - "可能我之前有些地方没考虑到，我们再来分析一下..."

2. **探索原因**：询问更多细节
   - "能多分享一下你在XX方面的感受吗？"
   - "除了这个，你在XX方面还有什么特别的感受？"

## 操作注意事项

### 1. 对话节奏控制
- 一次只分享2-3个主要观点
- 等待用户回应后再继续
- 根据用户兴趣调整讨论深度

### 2. 问题设计原则
- 选择用户容易回答的问题
- 避免过于私密或敏感的问题
- 问题要自然，像聊天一样

### 3. 价值导向
- 重点分享对用户有用的见解
- 提供可操作的建议
- 增强用户的自我认知

### 4. 灵活适应
- 根据用户类型调整沟通风格
- 允许用户主导话题
- 支持随时深入探讨某个点

## 🩺 健康预警维度（身弱/官杀重命必加）

> 实战观察（已脱敏）：身弱丙火命者在金水旺的流年（如丁酉/戊戌、己亥/庚子）易出现身心压力集中爆发——**金水旺年对身弱命的第一冲击是身心健康，不是学业成绩**。解盘必须带健康预警。

### 五行-脏腑映射表（中医基础理论）

| 五行 | 脏腑 | 对应身体/情绪 |
|---|---|---|
| 火 | 心、小肠 | 头面、眼、血脉、睡眠、精神热情 |
| 水 | 肾、膀胱 | 泌尿、耳、骨、内分泌、恐惧焦虑 |
| 木 | 肝、胆 | 筋、神经、目、**情绪疏泄（抑郁主木郁）** |
| 金 | 肺、大肠 | 呼吸道、皮肤、鼻 |
| 土 | 脾、胃 | 消化、肌肉、思虑 |

### 健康推断三原则

1. **日主被克**：日主五行弱而受官杀克 → 日主对应脏腑/部位受损（丙火→头面/心/眼/睡眠）
2. **最旺五行过旺**：旺者克及对象受伤（水旺 → 克火 → 心脑眼；且水主肾，水旺则肾负担）
3. **最弱五行薄弱**：弱处即短板（木弱 → 肝胆疏泄不足 → 抑郁焦虑、神经紧张；逢金年木更伤）

### 推演输出格式（含原因+部位+时段）

```
🩺 健康预警（依据五行生克推演）
| 部位/方面 | 原因 | 高危时段 | 预防 |
|---|---|---|---|
| 头疼/睡眠 | 水旺克火，火主头面 | 金水年(2028/2031/2033) | 子时前睡、少熬夜 |
| 情绪/抑郁 | 木弱肝郁，火弱神衰 | 秋冬金水月 | 运动疏泄、晒太阳 |
...
```

### 铁律
- 官杀重（水旺）身弱命：**金水年为身心预警年**，逢之主动减负，不做重大决定
- 木火帮身年为恢复窗口，正事优先安排
- **医学免责声明**：命理推演仅为传统文化视角的「结构理解」，不替代医疗诊断；抑郁等疾病必须遵医嘱。健康预警必须带此声明。

## 📅 每日运势（进阶功能）

> 用户已排盘并确定喜用神后，可随时查询今日/指定日期的运势。基于日干支五行与命主喜用神、忌神对比打分。

**调用方式**（skill_dir 即技能目录）：

```bash
python scripts/daily_fortune.py date=2026-08-09 day_master=丙 favorite=木,火 avoid=金,水
```

参数说明：
